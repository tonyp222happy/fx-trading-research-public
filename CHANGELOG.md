# Changelog

## 0.1.0 — 2026-08-12

Initial prepared public research framework:

- CSV OHLC(V) ingestion and resampling
- Markdown idea record + transparent concept catalog check
- deterministic strategy adapter contract
- next-bar execution backtest engine
- benchmark and risk-adjusted metrics
- rolling walk-forward parameter selection
- factor / Spearman IC analysis without an undeclared scientific-computing dependency
- signal combination helper
- reproducibility report and data hash manifest
- deterministic synthetic demo data generator
- tests and continuous integration
- explicit public/private research boundary

Production strategy code, platform-specific trading code, broker integration, private market data, and deployment logic are intentionally excluded.
